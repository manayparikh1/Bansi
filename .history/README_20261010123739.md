# Bansi

This is a website that I created from scratch that took WAY too long to complete but I wanted to learn too so it was worth it. Basically it talks about my favourite instrument which is a bansuri, and there is also a **interactive** bansuri in the bottom that is basically powered from your keyboard or cursor (your choice).

****So on your keyboard here is all the keys and what they equal!****

**SA** = A
**RE** = S
**GA** = D
**PA** = F
**DHA** = G 
**NI** = H
**SA** = J

## FEATURES

- Learn what a bansuri/bamboo flute really is
- Learn the history of the bansuri
- Learn about important players like Pannalal Ghosh and Hariprasad Chaurasia
- Learn how to bansuri is actually played without any sort of keys
- Explore the several swaras: **SA, RE, GA, MA, PA, DHA, NI**
- There is also an interactive bansuri which can be controlled with your keyboard
- There are a few different raga options which you can test out. 
- There are also a few different flute lengths and sounds which range from low, medium, and high in pitch.
- Tanpura Drone sounds are also available
